## 🚀 Featured Project

**[NTUC Income Eco Run Results Tracker](https://ntuc-income-eco-run-results-tracker.vercel.app/)**
Live results tracker for 16,600+ Eco Run participants across three years, built with a pipelined, 50-concurrent-request fetch architecture to work around the official race site's missing placement data. [Announcement post on r/SingaporeFitness](https://www.reddit.com/r/SingaporeFitness/comments/1sv8n1i/for_those_who_are_curious_about_the_leaderboard/) drew 33K views with a 100% upvote ratio.
